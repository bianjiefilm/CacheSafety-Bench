# Security Policy

## Scope

CacheSafety Bench is a benchmark project, not a production gateway. Please report:

- vulnerabilities in the local CLI or report generation
- unsafe defaults that could mislead users about Bad Hit Rate
- accidental inclusion of sensitive data in fixtures or docs

## Reporting

Please email `security@nextmodel.app` or open a private security advisory if the platform supports it.

Do not include real API keys, customer prompts, or confidential data in reports.

## Out of scope

- model quality disagreements without a reproducible benchmark case
- cost estimate differences caused only by provider-side pricing changes
- hosted gateway issues outside this repository
