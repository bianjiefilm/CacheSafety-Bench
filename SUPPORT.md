# Support

## Use this repository for

- benchmark usage questions
- dataset format questions
- report interpretation questions
- strategy interface questions

## Open an issue when

- the CLI fails on the bundled toy dataset
- the docs are unclear or contradictory
- a metric definition appears wrong
- a benchmark report suggests an obviously unsafe cache hit

## Before filing

- confirm you are using toy or non-sensitive data
- include the exact command
- include the config file
- include the generated JSON report when possible
